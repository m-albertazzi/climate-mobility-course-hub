10. **Overview text supplied by the course team** (Learning approach, Recognition, Practical information) is published as supplied, with these corrections confirmed by the course team: course dates 26 October – 4 December 2026; “an introduction and five online modules” (not 8); only the Diploma for Labour Migration Experts and Practitioners is mentioned. The “Who the course is for” section was removed at the course team’s request. The Overview layout (stats, about box, objective cards, phase and feature cards, module cards, recognition / practical-information split) is modelled on the reference hub, in the hero-image palette.
11. **Hero image** is shown as the header on every tab. The earlier Overview facts block, key dates and the requirements “to be confirmed” notice were removed at the course team’s request; the module list returns as cards (“Modules and live sessions”).
12. **Zoom and calendar buttons** — every live session has a “Join on Zoom” button and an “Add to calendar (.ics)” button; the Timetable has “Download all sessions (.ics)”. All sessions use the single Zoom link supplied by the course team. The calendar events carry the abstract, the Zoom link and the hub timetable link, and no speaker names or readings. Calendar times assume CET (UTC+1) for all dates, as in the timetable.

13. **Simulation tab (Three Shores)** — built from the course team's storyboard and scenario file (4 acts, 12 decisions, 48 options, 49 flags, 2 hard gates). Placed after Timetable. Every text shown to participants is the scenario text, unchanged. Added by the hub: the introduction screen, button and navigation labels, a short note on the tab (wording supplied by the course team: a learning tool in a fictional scenario; ratings reflect the course team's reading of ILO standards and guidance and are not official ILO positions), and the closing “Your path” list and text download.
14. **Scoring rule discrepancy** — the scenario file says a loss is `round(net × 0.5)`. The storyboard's own figures (all 192 option chips) and its four reference runs only match if a loss is also multiplied by `level / 50`, so losses shrink as an indicator nears zero. The player implements that version. With it, the four reference runs reproduce exactly (77/78/63/23, 77/82/80/29, 71/54/65/55, 35/9/33/83) and 60,000 random runs match the storyboard's playtest table. **Please confirm that this is intended and correct the `scoring.loss` line in the scenario file.**
15. **“Handbook” label** — options tagged “Echoes: Handbook” are shown as “Draws on the course modules”, so the hub does not present the handbook as a resource. The “Course reference” lines (for example “Module 4, Theme 1 and Box 8”) are kept as written, because the module numbers match the hub's Overview. Remove them if even these pointers are unwanted.
16. **Not shown** — the storyboard's list of “Instruments referenced” (conventions, recommendations and guidelines) is not displayed, in line with the earlier instruction that readings should not appear. The instrument named in each option's feedback is shown. The four reference runs, playtest tables and the notes for the hub are reviewer material and are also not shown. The list stays in `js/scenario.js` if it is wanted later.
17. **Open points from the storyboard** (still open, repeated here): content, framing and indicator balance are not cleared with ILO counterparts; statements about instruments need legal-officer review; the employers' chair as the final act versus a neutral convener; the Choice indicator should be tested with participants. The “Draft for review” label was removed at the course team's request and replaced by the note described in item 13, so these points are now only recorded here.
18. **Progress is not saved** — by design the hub stores nothing, so refreshing the page restarts the simulation. The storyboard suggests saving progress and giving facilitators a group view of paths; that would need a store the hub does not have.
